# Multimeter Engine

A cross-platform tool for hardware/system info gathering, disk/partition operations, system configuration, and external program execution. It also provides automatic stress testing, hardware/software state alerting, system backup for migration, and software issue fixing.

## Current Progress

| Feature                  | Linux       | Windows     |
| ------------------------ | ----------- | ----------- |
| Hardware info gathering  | Most        | Most        |
| System info gathering    | Done        | Done        |
| Partition operations     | In progress | None        |
| System configuration     | In progress | None        |
| External program calling | Done        | Done        |
